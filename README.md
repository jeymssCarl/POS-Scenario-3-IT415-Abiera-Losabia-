# Milk Tea POS — Scenario 3

A computer-based food ordering and point-of-sale (POS) application for a
milk tea and beverage shop. Built as the IT 415 Midterm Practical
Examination (Davao del Norte State College, Institute of Computing).

## Scenario

Scenario 3 — Milk Tea and Beverage Shop POS. Six hard-coded products;
cash payment only; no database; no login; no payment gateway.

## How to run

1. Clone this repository.
2. Open `index.html` directly in a modern browser (Chrome or Edge recommended).
3. No build step, no npm, no server required.

## Project structure

- `index.html` — entry point, three screen sections.
- `css/` — reset, layout, components.
- `js/` — catalog, models, cartLogic, payment, receipt, app.
- `assets/screenshots/` — evidence for submission.
- `ai_documentation.md` — Section VIII AI usage log.
